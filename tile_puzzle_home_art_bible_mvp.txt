Проект: Tile Puzzle Home
Версия: MVP 1.0
Платформа: Yandex Games / WebGL
Движок: Unity 6000.3.20f1, URP 2D
Базовый вертикальный макет: 1080×1920
Кодировка: UTF-8

ОБЩИЕ ПРАВИЛА

Стиль: мягкая уютная 2D casual-иллюстрация; округлые формы, крупные читаемые силуэты, без фотореализма и мелкого визуального шума.
Свет: сверху слева, тёплый. Тень: вниз вправо, мягкая.
Контур: #5B4038; никогда не использовать чисто чёрный.
Основная палитра:
#5B4038 — контур и основной текст
#6E5148 — глубокая тень
#9A766A — мягкая тень
#FFF4E3 — кремовый
#F5DFC3 — светлый бежевый
#E7C39B — тёплый бежевый
#E98B73 — персиковый акцент
#D96F5F — коралловый акцент
#F3C889 — золотой акцент
#7FAF86 — тёплый зелёный
#52745A — тёмный зелёный
#A99AC8 — лавандовый
#88B8C8 — голубой
#B9ADA5 — заблокированное состояние
#3C2D29 — затемнение

Экспорт: PNG-32 с прозрачностью для спрайтов; PNG без прозрачности для фонов. sRGB. Без лишних метаданных.
Unity по умолчанию: Sprite (2D and UI), PPU 100, Bilinear, Mip Maps Off для UI/плиток, Wrap Clamp, Read/Write Off, Alpha Is Transparency On, Max Size по фактическому размеру.
Sprite Atlas: padding 4 px, для свечений 8 px; Allow Rotation Off.
У каждого отдельного спрайта оставить 6% прозрачного поля; у свечений и теней — 10%.
